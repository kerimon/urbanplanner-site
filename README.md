# urbanPlanner

Static website for urbanPlanner – construction services and heavy equipment rental.

## Host on GitHub Pages
1. Create a new repository on GitHub and upload `index.html` (and this README) to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site will be live at `https://<your-username>.github.io/<repo-name>/`.
